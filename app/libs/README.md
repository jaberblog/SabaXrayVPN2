# libv2ray.aar

The binary is intentionally not committed to this source ZIP. GitHub Actions downloads the pinned official AndroidLibXrayLite release before compiling:

`https://github.com/2dust/AndroidLibXrayLite/releases/download/v26.11.9/libv2ray.aar`

For a local Android Studio build, place the official file at:

`app/libs/libv2ray.aar`
